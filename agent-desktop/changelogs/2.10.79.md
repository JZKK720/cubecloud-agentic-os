## What this release changes

V2.10.78 → V2.10.79 is a **dev-server + screenshot capture fix** release.
3 issues blocked the screenshot capture pipeline and the dev server CSS
loading; all are now fixed.

### Dev server CSS loading fix

- **Removed `@tailwindcss/vite` plugin** from `electron.vite.config.ts`.
  The project uses pure CSS custom properties (no Tailwind directives),
  and the Tailwind v4 plugin's parser was throwing "Missing opening {"
  on `color-mix()` calls in `main.css`, causing the CSS to return a 500
  error and breaking the dev server renderer.

### CSS syntax fix

- **Fixed missing selector** in `main.css`: the `/* Skills loading */`
  block had CSS properties without a selector or opening brace, causing
  a PostCSS "unexpected close" error. Added the `.skills-loading`
  selector.

### Screenshot capture fix

- **Fixed `run-preview.cjs`** to pass `SKIP_MOCK_GATEWAY=1` to
  `capture-previews.js`, preventing a port 8765 EADDRINUSE conflict
  when both scripts tried to start their own mock gateway.
- **Fixed `capture-previews.js` `clickTab`** to call
  `scrollIntoViewIfNeeded` before clicking and increase timeout from
  5s to 10s, preventing tab-click failures on off-screen sidebar buttons.
- **Created `capture-remaining.cjs`** — a focused script that connects
  to the existing CDP endpoint and captures screenshots using
  `button[data-view="..."]` selectors (more reliable than text matching).
  Used to capture the 8 tabs that the main capture script missed
  (tools, workspace, schedules, gateway, mcp, settings, swarm, knowledge).

### Real screenshots captured

All 24 preview screenshots are now real captures from the running
desktop build (12 captured by `capture-previews.js`, 8 by
`capture-remaining.cjs`, 4 onboarding screens pre-existing). The
placeholder PNGs for swarm.png and knowledge.png have been replaced with
actual screenshots of the Swarm and Knowledge Vault screens.
