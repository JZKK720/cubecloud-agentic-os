## What this release changes

V2.10.79 → V2.10.80-draft is the **Workspace Console P0 + P0.5** slice: the
first implementation of the workspace↔desktop control-console contract
(`docs/plans/2026-10-06-cubecloud-agent-integration-plan.md` row A) and the
EverMind replan P0.5 (`docs/plans/2026-10-06-evermind-memory-harness-replan.md`).

### Workspace Console probe (P0 — contract row A)

- **New module** `src/main/cubecloud-agent-probe.ts`: stateless HTTP probe of
  the AI Workspace server — `GET /health` (required) + opportunistic
  `GET /v1/info` / `GET /v1/stack/status` (optional, older builds 404).
  Never throws; `normalizeWorkspaceOrigin()` accepts loopback-host http
  origins only (the same allow-list class as `isAllowedWebviewUrl`), so a
  stray user-entered remote URL can never be probed as loopback.
- **New IPC channels** in `src/main/index.ts`: `workspace-probe` (health +
  identity) and `workspace-probe-url` (the loopback origin the renderer will
  feed the hardened webview embed in row C — pinned to
  `http://127.0.0.1:6767` until the P5 config center persists an override).
- **Preload bridge** (`src/preload/index.ts` + `index.d.ts`): `workspaceProbe`
  / `workspaceProbeUrl` with a documented `WorkspaceProbeResult` shape.
- **Tools screen card** (`src/renderer/src/screens/Tools/Tools.tsx`): the
  "AI Workspace (cubecloud-agent)" console card — Reachable/Unreachable pill,
  version from `/v1/info` when present, attached-at origin, refresh button.
  Follows the existing Agent-Reach/GBrain panel conventions.

### Laya decision middlewares (DM1 — decision-core replan §D3.3)

- **New module** `src/main/laya-middlewares.ts`: two before_model
  middlewares over the Laya System-1 decision engine, both **fail-open**
  and **toggle-gated** (config keys `agent.laya_guard` /
  `agent.laya_route`, default OFF — zero Laya calls unless opted in):
  - `laya-guard` — pre-LLM prompt screening via the guard question set
    (choice verdict `benign|suspicious|injection` + ordinal severity 0–3,
    confidence-gated abstention via `minConf`). Annotates the context for
    the audit trail; **never blocks by itself** — blocking stays with
    tool-policy + governance approvals.
  - `laya-route` — advisory lane hint (`hermes|ironclaw|openclaw|raven|
    workspace|none`); never selects the lane, annotation only.
- **Injected client** (`LayaDecideFn`): in production the caller targets a
  local `laya-serve` (`LAYA_BASE_URL`, default `http://127.0.0.1:8000`,
  optional bearer `LAYA_API_KEY`, 10 s bounded) with the `/v1/systemone`
  contract; in tests a stub — **no checkpoints ever load in CI**.
- **Wired in `hermes.ts`**: the pair composes AHEAD of the platform
  chain (tool-policy → memory → headroom → compaction → runtime-route);
  on any Laya error/skip the whole chain proceeds unchanged (chain-wide
  fail-open rule).
- Typed-decision semantics honored: values may be null (abstention under
  minConfidence) with confidence still reported; routing model + reason
  are carried in the stats for the audit log.

### Raven harness adapter (I-phase — EverMind replan §5, row I)

- **New module** `src/main/harnesses/raven-harness.ts`: the real adapter
  replacing the throwing registry stub for the Raven lane. Raven's
  gateway is **OpenAI-compatible on 8855** (WebUI 18793 is a separate
  surface): `runTurn` streams `POST /v1/chat/completions` SSE chunks
  into the platform `Harness` delta contract (text/reasoning/done),
  `oneShot` does the non-streaming round-trip (usable as the utility for
  decision slots pointed at Raven), `compactHistory` is a profile-
  truthful no-op (`supportsCompaction: false`), and `resetSession`/`close`
  are honest no-ops (Raven owns session state server-side).
- **Base-URL resolution** mirrors the connection chain with the Raven
  port pinned: operator override `runtime.provider_url` → remote/ssh URL
  with the port swapped to 8855 → local default `127.0.0.1:8855`; optional
  bearer key from the connection config (vault side, never inlined).
- **Fail-open adapter semantics** (mirroring Hermes): a gateway failure
  yields a final `done` delta through the router's error path — nothing
  throws out of the generator; a `[DONE]` frame or a completed stream
  yields `done` with the sessionId preserved.
- **Registry**: `createHarnessRegistry()` now wires the real adapter —
  `runtime-registry.ts`'s P0.5 detected-aware optional snapshot and the
  catalog's `optional` status now match the runtime truth (stub throw
  eliminated; verified by test).
