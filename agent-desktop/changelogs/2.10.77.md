# cubecloud-agent-desktop v2.10.77 — release notes

**Source:** V2.10.75 on `origin/main` of
[JZKK720/cubecloud-agentic-os](https://github.com/JZKK720/cubecloud-agentic-os)
**Supersedes:** v2.10.75 (tag on `origin/main`)
**Internal version:** `2.10.77` (in `agent-desktop/package.json`)

## What this release changes

V2.10.75 → V2.10.77 is a **Tier 1 add-on build + onboarding restructure**.
16 feature commits across voice integration, runtime activation, security
gates, eval framework, skill sharing, and full i18n coverage.

### Voice STT/TTS

- **Handy local-first STT** — `handy-stt.ts` detects Handy on PATH,
  toggles transcription via `handy --toggle-transcription`. Primary input
  path when Handy is available (offline, local-first).
- **Cloud STT fallback** — `voice-stt.ts` sends audio buffers to Groq
  Whisper or OpenAI Whisper (resolves `GROQ_API_KEY` >
  `VOICE_TOOLS_OPENAI_KEY`). MediaRecorder API captures audio in the
  renderer.
- **OpenAI TTS** — `voice-tts.ts` synthesizes speech via `tts-1` model
  (nova voice). Speaker button on agent messages (hover-visible).
- **Chat UI** — Mic button with recording pulse + transcribing spinner
  states. TTS speaker button with speaking/ generating states.

### Runtime: Raven (EverMind) activation

- **Raven added as 4th runtime** — port 8855, `integrationStatus: "optional"`.
  The desktop auto-detects Raven on port 8855 and surfaces it as a runtime
  choice on the Welcome screen.
- `RuntimeProviderId` extended, `gateway-runtime-presets.ts` updated with
  Raven preset, `runtime-defaults.ts` adds `RAVEN_DEFAULT_PORT = 8855`.
- `detectGatewayRuntime()` in `hermes.ts` probes `/health` for
  `"runtime":"raven"` body, only on port 8855.

### Onboarding restructure

- **Primary line-up**: Wire Hermes API + Wire Raven (EverMind) + Hermes via
  SSH + Raven via SSH
- **Secondary line-up**: IronClaw + OpenClaw remain in the runtime lane
  picker on the remote/SSH panels
- SSH panel: vertical SSH Host/Port layout, runtime lane picker with all
  4 runtimes, runtime-specific subtitles

### SkillSpector hard gate

- `installSkill()` in `skills.ts` now scans with SkillSpector after Hermes
  copies. Blocks on exit code 1/2, uninstalls malicious skills.
- `installSkillFromGitUrl()` — clones a git repo, finds `SKILL.md`, scans
  with SkillSpector, copies to profile. Skill sharing via git URL from
  the Skills screen.

### Agent eval framework

- `eval-harness.ts` with 5 starter cases: echo, math, code-aware,
  safety-refusal, tool-awareness. Pure `scoreEvalResponse()` keyword
  scorer (unit-tested, 11 tests). `runEvalSuite()` I/O wrapper calling
  the gateway `/v1/chat/completions` endpoint.
- Settings screen: "Run Agent Eval" button + results table.

### Tool surface integration (Tier 2 add-ons)

- **GBrain** — `gbrain-probe.ts` runs `gbrain doctor --json`. Status panel
  on Tools screen.
- **Graphify** — `graphify-probe.ts` discovers graphify/graphifyy on PATH,
  runs `--version`. Status panel on Tools screen.
- **OfficeCLI** — added to `AGENT_CLI_CATALOG` + MCP registry.
- **Browser Use** — added to MCP registry.
- **7 new MCP registry entries**: gbrain, wigolo, watch-skill,
  loop-engineering, browser-use, officecli, graphify.

### IPC surface

- **9 new IPC channels**: gbrain-probe, voice-transcribe, voice-synthesize,
  handy-detect/toggle/cancel, graphify-discover/version, eval-run,
  skill-install-git.
- **Preload**: 9 new methods + 6 new type interfaces.
- **IPC audit**: all 15 new channels categorized in `audit-smoke-safe.cjs`.
  Result: 155 safe, 0 unknown.

### i18n (full coverage)

- **Voice/TTS keys** added to all 8 locales (en, zh-CN, zh-TW, ja, es,
  pt-BR, pt-PT, id): `voiceInput`, `voiceRecording`, `voiceTranscribing`,
  `voiceHandy`, `voiceCloud`, `speakAloud`, `stopSpeaking`,
  `generatingSpeech`.
- **Tools panel keys** added to all 8 locales: `panels.gbrain/wigolo/
  watchSkill/browserHarness/officecli/graphify` with title, subtitle,
  hint, notInstalled, healthy/unhealthy/installed.
- **SSH panel keys** added to all 8 locales: `connectSshPanelTitle`,
  `connectSshSubtitleHermes/Openclaw/Ironclaw`.
- **i18n coverage check: 0 missing keys** across all locales.

### CSS fixes

- Runtime lane button overflow — `flex-wrap: wrap` + smaller font/padding
  so 4 buttons fit in the 420px card.
- SSH grid — `flex-direction: column` for vertical SSH Host/Port stacking.

### Documentation

- `AGENTS.md` + `agent-desktop/AGENTS.md` updated: Raven status, integrated
  surfaces list, CLI count (25→35), runtime ports table.
