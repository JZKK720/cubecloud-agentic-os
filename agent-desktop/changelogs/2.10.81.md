# cubecloud-agent-desktop v2.10.81 — release notes

**Source:** `feat/console-kernel-c0` branch (12 commits, `2bc9ee6`…`65fa252`)
**Supersedes:** v2.10.80
**Internal version:** bumped to `2.10.81` in `agent-desktop/package.json`
(the root `package.json` also carries `2.10.81` — it had drifted to `2.10.79`).

## What this release changes

V2.10.80 → V2.10.81 is the **headless console kernel** slice: Agentic OS is
split into a runtime that no longer needs Electron and interchangeable
shells over it, and that runtime is proven running in a container against
the live AI Workspace.

### Console kernel (C0/C1)

- **New** `agent-desktop/console-backend/`: the kernel proper —
  `server.ts` (boot), `registry.ts` (route registry), `generic-bridge.ts`
  (registers every desktop IPC channel as a kernel capability from the
  committed `dispatch-table.json`), `shell.ts` (serves `out/renderer` with
  an injected `window.hermesAPI` → fetch/SSE shim), plus the parity,
  coverage, and selftest harnesses.
- **295 capabilities** served over HTTP; parity check asserts the kernel
  surface matches the preload (295 ↔ 291 invoke methods).
- `electron-stub.ts` + `resolve-ts-loader.mjs` let the Electron-free
  modules boot under plain `node --experimental-strip-types`.
- `homer.ts`: the Electron-free home/path constants lifted out of
  `installer.ts`, so 29 main-process modules no longer transitively pull
  the installer wizard.

### ManagedApp framework (Phase B)

- `src/main/managed-apps/`: one `ManagedApp` contract + a 16-adapter roster
  (workspace, everos, 4 gateways, 10 tool surfaces), mode-aware lifecycle,
  and `desktop.json` config-block isolation with a CI cross-block-write ban.

### AI Workspace management surface (Phase C)

- `WorkspaceConsole` is now a five-tab operator surface — Overview
  (probe + supervisor lifecycle), Settings (env provisioning,
  fingerprints-only), Sessions (read-only mirror), Policies (tolerant of
  older builds' 404s), Approvals (the ONE workspace write: the human
  verdict) — replacing the bare `<webview>` embed.
- `workspaceConsole` i18n namespace + `navigation.workspaceConsole` label
  across 8 locales; new `.workspace-console-*` styles.
- Quality gate (`docs/plans/2026-10-13-phase-c-quality-gate.md`): fixed a
  WCAG-AA contrast miss and a suppressed focus ring.

### De-Electronization (Phase E)

- `src/renderer/src/utils/platform.ts` replaces every `window.electron`
  read; two of the six were unguarded crashes in the browser shell.

### Container (Phase F)

- `.dockerignore` (build context 1065 MB → 22 MB) and a corrected
  `console-backend/Dockerfile`: installs `agent-desktop` from its own
  lockfile, keeps `electron`/`@electron-toolkit` available for the build,
  copies `tsconfig.base.json`, and symlinks `@cubecloud/platform-core` into
  `node_modules` (so Node 24 can strip its types).
- `CONSOLE_KERNEL_HOST` (default loopback) lets the container bind
  `0.0.0.0`; `CUBECLOUD_AGENT_DEFAULT_URL` is now env-aware so the container
  attaches to the host workspace.
- **Verified end-to-end in-container:** healthy, `/health` 295 caps,
  FirstRunScan found the workspace at `http://host.docker.internal:6767`,
  connected, and the AI Workspace panel read "Reachable".

### Electron-free enforcement (Phase G)

- `tests/console-kernel-electron-free.test.ts`: walks the kernel entry's
  transitive import closure (276 modules) and fails if any reachable module
  imports `electron`. See `docs/plans/2026-10-13-phase-g-readiness-audit.md`.

probe through a container→host-gateway hop can exceed it (warm: 1.58 s).
Not a defect; flagged for the next pass.
