# cubecloud-agent-desktop v2.10.78 — release notes

**Source:** `origin/main` of
[JZKK720/cubecloud-agentic-os](https://github.com/JZKK720/cubecloud-agentic-os)

## What this release changes

V2.10.77 → V2.10.78 is an **architectural foundation** release.
18 commits across 10 adopted architectural modules, 3 competitive gap
features, design audit fixes, i18n completion, and typecheck cleanup.

### Architectural adoption (P1–P10)

10 modules adopted from openworker, qm, and skills-bundle-kit, all in
`packages/platform-core/`:

- **P1 Harness** — `harness.ts` + `HermesHarness` adapter wrapping the
  existing `sendMessage()` callback API as `AsyncIterable<HarnessTurnDelta>`.
  4-adapter registry (Hermes + 3 stubs).
- **P2 Provider router** — prefix routing (`provider:model` → client),
  cache-per-provider, stream + complete interfaces.
- **P3 Tool policy** — regex-based command screening with allow/deny/
  require_approval. `scannableCommand()` recursively extracts `$(...)`,
  heredocs, and nested subshells. Three-tier `SecurityPosture` (dangerous/
  auto/strict). `ToolLedger` for idempotent retry.
- **P4 Memory service** — scoped memory vault, `foldCapture()` for
  conversational folding, `normalizeEntryText()` sanitization.
- **P5 Auto-compaction** — token estimation, `pickBoundary()` for split
  point, `extractWorkingState()` (mechanical todo + file extraction),
  `compactTurnHistory()` summarizer.
- **P6 Progressive skills** — disclosure levels (flat → categorized →
  detailed) based on usage frequency.
- **P7 Skills discovery** — flat + categorized layout discovery.
- **P8 Steering inbox** — `SteeringQueue` + `ApprovalInbox` for
  human-in-the-loop approval routing. Chat header badge for pending
  approvals.
- **P9 Run queue** — `RunStore` with enqueue/retry, `isNonRetryable()`
  classification.
- **P10 Subagent** — `runSubagent()` with `READ_ONLY_TOOLS`,
  `createSubagentConfig()`, `validateSubagentConfig()`.

### Competitive gaps (G1–G3)

- **G1 IM Channels** — `Channel` interface, `ChannelRouter`,
  `normalizeMessage()`. Three adapter stubs: Feishu (`parseFeishuEvent`),
  DingTalk (`parseDingTalkEvent`), WeCom (`parseWeComEvent`). Gateway UI
  panel for IM channel configuration.
- **G2 Swarm** — `SwarmManager` (max 5 concurrent subagents, message
  recording). Swarm screen UI with agent list, task dispatch, message
  flow, and live SVG topology graph (`TopologyGraph.tsx`) with status-
  colored nodes, edge flow animations, hover highlight, and
  `prefers-reduced-motion` support.
- **G3 Knowledge Vault** — `KnowledgeVault` with inverted-index full-text
  search, `tokenize()`. Knowledge screen UI with file tree, Markdown
  editor with live preview, and search bar. Agent integration: vault
  search results injected into Hermes system prompt.
