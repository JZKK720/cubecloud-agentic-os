# cubecloud-agent-desktop v2.10.85 — release notes

**Source:** \origin/main\ of
[JZKK720/cubecloud-agentic-os](https://github.com/JZKK720/cubecloud-agentic-os)
**Supersedes:** v2.10.84

This release ships the OfficeCLI line of work and the managed-app evidence
fixes that landed after v2.10.84. It contains no breaking changes.

## What this release adds

### OfficeCLI as a first-class tool

OfficeCLI was already an MCP server users could install by hand, but the
desktop offered no way to actually invoke it. \gent-desktop/src/main/officecli.ts\
spawns the binary with a fixed verb allow-list (\iew\, \alidate\, \pply\,
\dump\), refuses shell metacharacters, resolves every path argument through an
allow-list of roots (home and temp, extensible via \OFFICECLI_ALLOWED_ROOTS\),
and caps output. The Tools screen gains a run panel and a status probe; IPC
channels \officecli-run\, \officecli-view\, \officecli-status\ are registered as
read-class except \un\, which the IPC audit classifies explicitly.

New i18n keys ship in all 8 locales (en, es, id, ja, pt-BR, pt-PT, zh-CN,
zh-TW); zh-CN stays at full coverage.

### Read-only Univer spreadsheet viewer

\OfficeCliSheetView\ renders \officecli view <file> text --json\ output as a
read-only Univer grid in the Tools screen. OfficeCLI remains the only writer —
Univer displays what it reports and cannot mutate the file.

Univer ships in a lazily-loaded chunk (~11.9 MB) that is fetched only when the
viewer is opened. The entry chunk is unchanged at ~8 MB. The CSS is imported
with the component.

**Verification status.** The viewer was exercised end-to-end over CDP against
a real dev build: Tools -> View as spreadsheet -> Univer mounts
(\status: ready\, 2 canvases, zero console errors). It has **not** been
exercised in a packaged installer, and the Univer stack has not been run under
the packaged CSP. Treat it as a preview until an operator install confirms it.

Two defects were fixed before merge, both caught only by actually running it:

- The mount effect depended on the parsed sheet object, which a fresh
  \JSON.parse\ produces every render. Univer mounted and unmounted in a loop
  and \host.replaceChildren()\ threw \emoveChild\ on every frame; the viewer
  never left \mounting\. Now the parse is memoized on the raw payload and the
  effect depends on the memoized value.
- The cleanup no longer clears the host's children; Univer owns those nodes.

### Managed-app evidence fixes

- DataFlow and OpenViking endpoints on the host were unreachable from the
  kernel; the candidate-rule handling is now unified across host-run apps.
- \dsh\ no longer reports a false green when it is absent.
- The integration plan and the plan index record the verdicts.

### i18n mojibake repair

UTF-8 that had been decoded as GBK and re-saved was repaired at the byte
level; the mojibake gate now catches that class rather than only U+FFFD.
