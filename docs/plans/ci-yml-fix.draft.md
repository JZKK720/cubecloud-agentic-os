# Plan: Fix the two broken CI jobs in `.github/workflows/ci.yml`

> proposal, not a committed change. Do not implement without owner sign-off.

## Problem

Two jobs in `.github/workflows/ci.yml` (root) reference scripts/tests
that do not exist. A green CI run therefore proves nothing about the
test suite.

### Job 1: `desktop-shell-checks`

**Current command:**
```yaml
npm run test -- App.gateway.dom.test.tsx src/renderer/src/App.kanban.dom.test.tsx src/main/runtimeSessions.test.ts
```

**Problem:** None of these 3 files exist under `agent-desktop/`.
`vitest.config.ts` has `passWithNoTests: true`, so vitest exits 0
having run zero tests.

### Job 2: `desktop-shell-electron-smoke`

**Current command:**
```yaml
npm run test:electron-smoke
```

**Problem:** `test:electron-smoke` is not defined in
`agent-desktop/package.json`. The closest real script is `smoke`
(`node scripts/smoke-all.js`), but that requires a running dev
electron with `ENABLE_CDP=1 CDP_PORT=9222`, which CI does not start.

## Proposed fix (two options each — owner picks)

### Job 1 fix — pick one

**Option A (recommended): run the full suite.**
```yaml
- name: Run agent-desktop test suite
  run: npm run test --workspace cubecloud-agent-desktop
```
Asserts `Test Files > 0` in the output. Cost: longer CI run (~95
test files). Benefit: actually catches regressions.

**Option B: run a real focused subset that exists.**
```yaml
- name: Run runtime-focused tests
  working-directory: agent-desktop
  run: |
    npx vitest run tests/gateway-runtime-presets.test.ts \
      tests/kanban-unsupported.test.ts \
      tests/hermes-auth.test.ts \
      tests/docker-runtimes.test.ts
```
Faster, but narrower. Must be kept in sync as files rename.

### Job 2 fix — pick one

**Option A (recommended): remove the job.**
The CDP smokes need a running dev electron and are not suitable for
headless CI without significant setup. Delete the
`desktop-shell-electron-smoke` job. Document that CDP smokes are a
local-only / pre-release manual step (already the case in practice).

**Option B: wire it to a real headless smoke.**
Add a `test:smoke-headless` script to `agent-desktop/package.json`
that runs only the non-CDP smokes (e.g. the 2 in-repo Vitest smokes
`tests/hermes-agent-attach.smoke.test.ts` and
`tests/ironclaw-attach.smoke.test.ts`, which spin up fake loopback
servers and need no external process). Point the CI job at that.
